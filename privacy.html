SNSアプリ プライバシーポリシー

ニューライフ開発株式会社（以下「当社」）は、当社が運営するSNSブランド「Japan Home Note」（ジャパンホームノート／日本置业笔记、@japanhomenote）の投稿管理アプリケーション（以下「本アプリ」）における情報の取り扱いを、以下のとおり定めます。当社は、個人情報の保護に関する法律（個人情報保護法）その他の関係法令を遵守します。

施行日：2026年10月26日

2. 本アプリの目的

本アプリは、当社が作成したコンテンツ（画像・動画・文章）を、当社自身が管理するInstagram、Threads、YouTube、TikTok、Xの各アカウントに投稿するためだけに使用する社内ツールです。一般の利用者に提供するものではなく、第三者のアカウントへの投稿や、第三者のアカウントへのログインは行いません。

3. 取得する情報

  • 当社自身のアカウントについて各プラットフォームがOAuth認証で発行するアクセストークン、および当社アカウントのID・投稿結果（投稿ID、公開状態など）
  • 本アプリは、当社以外の利用者、フォロワー、視聴者その他第三者の個人情報を取得・収集・保存しません。

4. 利用目的

取得した情報は、当社アカウントへのコンテンツ投稿と投稿結果の確認のためにのみ利用します。広告配信、分析目的の販売、第三者への提供には利用しません。

5. 保管と安全管理

アクセストークンは、当社が管理する端末内に暗号化して保存し、外部サーバーやクラウドには保存しません。アクセスは当社の担当者に限定し、不要になったトークンは速やかに削除・失効させます。

6. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。投稿のため、各プラットフォーム（Meta、Google、TikTok、X）の公式APIに当社コンテンツを送信します。

7. YouTube API サービスの利用

本アプリはYouTube API Servicesを使用しています。本アプリを利用することにより、YouTube利用規約に同意したものとみなされます。Googleによる情報の取り扱いについてはGoogleプライバシーポリシーをご確認ください。本アプリへのアクセス許可は、Googleのセキュリティ設定ページからいつでも取り消すことができます。

8. データの削除・開示等の請求

本アプリに関する情報の開示、訂正、利用停止または削除をご希望の場合は、info@newlife-dev-group.com までメールでご連絡ください（件名に「Japan Home Note データ削除依頼」とご記載ください）。ご本人確認のうえ、法令に従い遅滞なく対応し、削除完了をメールでお知らせします。また、各プラットフォームの設定画面から本アプリへの連携をいつでも解除できます。

9. 改定

本ポリシーは必要に応じて改定し、本ページに掲載した時点から効力を生じます。

中文版（隐私政策）

生效日期：2026年10月26日。ニューライフ開発株式会社（以下「本公司」）为其运营的SNS品牌「Japan Home Note」（日本置业笔记，@japanhomenote）的发帖管理程序（以下「本程序」）制定本政策，并遵守日本《个人信息保护法》等相关法律。

  • 本程序是内部工具，仅用于将本公司自己制作的内容发布到本公司自有的 Instagram、Threads、YouTube、TikTok、X 账号，不向公众提供，不代他人发帖。
  • 仅获取各平台通过 OAuth 为本公司账号签发的访问令牌及发帖结果；不收集任何其他用户、粉丝或观众的个人数据。
  • 令牌加密保存在本公司管理的本地设备中，不上传至外部服务器，不向第三方提供（法律规定的情况除外）。
  • 本程序使用 YouTube API 服务。使用本程序即表示同意 YouTube 服务条款；另请参阅 Google 隐私权政策。可随时通过 Google 安全设置页面 撤销授权。
  • 如需查询、更正或删除数据，请发送邮件至 info@newlife-dev-group.com（标题注明「Japan Home Note 数据删除请求」），本公司确认身份后将依法及时处理并邮件告知结果。
