アクセス解析ツールについて

当ウェブサイトでは、サイト改善を目的として、次のアクセス解析ツールを利用しています。改正電気通信事業法の外部送信規律に関し、外部の事業者へ送信される内容は次のとおりです。

Cloudflare Web Analytics

送信先
Cloudflare, Inc.（Cloudflare Web Analytics）
送信される情報
Cookie を使用せず、IPアドレスを保存しない方法で集計するアクセス情報です。
利用目的
サイト改善

Microsoft Clarity

送信先
Microsoft Corporation（Microsoft Clarity）
送信される情報
Cookie 等を用いて取得する、クリック・スクロール等の利用状況です。ヒートマップ等で分析します。入力内容はマスキングされます。個人を特定する目的では利用しません。IPアドレスは匿名化されます。
利用目的
サイト改善

オプトアウト

各事業者の取り扱いは、次のページで確認できます。ブラウザの Cookie 設定から、Cookie の受け入れを制限することもできます。

  • Microsoft プライバシーステートメント（https://privacy.microsoft.com/privacystatement）
  • Microsoft Clarity（https://clarity.microsoft.com/terms）
  • Cloudflare（https://www.cloudflare.com/privacypolicy/）
